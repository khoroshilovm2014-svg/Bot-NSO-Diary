# ===========================================================================
# NSO Diary — как выложить API в интернет БЕЗ своего сервера и без туннелей
#
# Проблема: Telegram Mini App требует HTTPS-адрес. Туннели (cloudflared)
# на многих хостингах запрещены — за них блокируют аккаунт.
#
# Решение: хостинг, который сам выдаёт HTTPS-поддомен.
# В проекте уже готовы файлы для двух таких: Dockerfile и render.yaml.
# ===========================================================================

# ---------------------------------------------------------------------------
# ВАРИАНТ 1. Render (рекомендую)
# ---------------------------------------------------------------------------
#
# Что даёт: https://имя.onrender.com — настоящий HTTPS, домен уже есть,
# бесплатно, карта не нужна.
#
# Минус: бесплатный сервис засыпает после ~15 минут без запросов.
# Первый запрос после сна поднимается 30–60 секунд.
# Для теста и небольшой школы — приемлемо.
#
# Шаги:
#   1. Зарегистрироваться: https://render.com (через GitHub).
#   2. Создать пустой репозиторий на GitHub, загрузить туда содержимое
#      папки bot/ (можно через веб-интерфейс «uploading an existing file»).
#      ВАЖНО: .env НЕ загружать — секреты вводятся в панели Render.
#   3. Render → New → Blueprint → выбрать репозиторий → Apply.
#      Render прочитает render.yaml и создаст сервис.
#   4. В созданном сервисе → Environment → заполнить секреты:
#         BOT_TOKEN           = 8865586574:...
#         WEBHOOK_SECRET      = 17JaIx7MJAE_31uxJOK3h65UeSI_FRiU
#         JWT_SECRET          = wZgE5XCmIq07jhTJsPOM1fp4SYpZGUGhQCVb9tvi9HUaxyRVZt-yNpbIfJZgDH9I
#         SUPABASE_SERVICE_KEY= sb_secret_vzMjR1xpYWymgcLiqe92Xw_OExGdMRu
#      (SUPABASE_URL и BOT_USERNAME уже прописаны в render.yaml)
#   5. Дождаться деплоя, скопировать адрес вида https://nso-diary-api.onrender.com
#   6. Environment → PUBLIC_BASE = этот адрес → Save (сервис перезапустится).
#   7. Открыть https://адрес/api/health — должно быть
#         {"ok":true,"db":"supabase","bot":true,"demo":false}
#   8. В логах Render появится: [bot] webhook установлен: ...
#   9. Проверить бота: t.me/nso_diary_bot → Start → «Получить код».
#
# Если сервис долго не поднимается — это нормально для бесплатного тарифа,
# подождите минуту и обновите страницу.

# ---------------------------------------------------------------------------
# ВАРИАНТ 2. Hugging Face Spaces (тоже бесплатно, без карты)
# ---------------------------------------------------------------------------
#
# Что даёт: https://имя-пространства.hf.space — HTTPS, стабильный адрес.
# Контейнер работает на Docker, засыпает после 48 часов без визитов
# (намного реже, чем Render).
#
# Шаги:
#   1. Регистрация: https://huggingface.co/join
#   2. New → Space → имя nso-diary-api → SDK: Docker → Blank → Create.
#   3. Files → Add file → Upload files: загрузить содержимое папки bot/
#      (Dockerfile, main.py, requirements.txt, README.md, app/, webapp/).
#      .env НЕ загружать.
#   4. Settings → Variables and secrets → New secret, добавить по одному:
#         BOT_TOKEN, WEBHOOK_SECRET, JWT_SECRET, SUPABASE_SERVICE_KEY,
#         SUPABASE_URL=https://surbkjmviyyvvrajhjkp.supabase.co,
#         BOT_USERNAME=nso_diary_bot,
#         CORS_ORIGINS=https://diary-nso.vercel.app,
#         DEMO_MODE=0
#   5. Дождаться сборки (2–4 минуты), открыть вкладку App.
#   6. Адрес пространства: https://<логин>-nso-diary-api.hf.space
#      Добавить его как секрет PUBLIC_BASE и перезапустить (Settings → Restart).
#   7. Проверить /api/health.
#
# ВАЖНО: Space по умолчанию публичный — код видят все.
# Секреты в Settings → Secrets видны только вам, в образ они попадают
# как переменные окружения. Файл .env в репозиторий не кладём.

# ---------------------------------------------------------------------------
# ЧЕГО НЕ ДЕЛАТЬ
# ---------------------------------------------------------------------------
#
# - Не запускать cloudflared на Pterodactyl-хостингах (NomadHost, Helia и т.п.) —
#   за это блокируют аккаунт, как уже случилось.
# - Не загружать .env в публичный репозиторий: там токен бота и
#   service_role ключ Supabase.
# - PythonAnywhere НЕ подходит: на бесплатном тарифе исходящие запросы
#   разрешены только к белому списку сайтов, а api.telegram.org в него не входит —
#   бот не сможет работать.

# ---------------------------------------------------------------------------
# ПОСЛЕ ДЕПЛОЯ
# ---------------------------------------------------------------------------
#
# 1. Адрес API вписать в config.js (корень проекта, сайт):
#        var DEPLOY_API = 'https://ваш-адрес';
#
# 2. Добавить домен сайта в CORS_ORIGINS на хостинге, иначе браузер
#    заблокирует запросы. Например:
#        CORS_ORIGINS=https://diary-nso.vercel.app,https://nso-diary.ru
#
# 3. Перезалить сайт на Vercel.
